# 云听搜索接口接入记录（2026-10-09）

> 来源：`接口/云听/搜索接口分析报告.md`（v4，app 通道签名完全复现）。
> 本轮把逆向成果接入 AudioFlow：**关键词搜索专辑** 全链路可用（单平台 + 聚合 + ID 直达）。

## 一、接入的接口

```
GET https://ytmsout.radio.cn/search/search/findSearchResourceList
      ?keyWord=<词>&searchTabId=<tab>&contentType=<int>&pageNo=<int>&sortType=<int>
```

| 参数 | 取值 | 说明 |
|------|------|------|
| `keyWord` | 搜索词 | 中文直传，参与签名 |
| `searchTabId` | `2` 专辑 / `''` 综合 | 项目固定先用 2，空则回落 '' |
| `contentType` | `1` 专辑 / `0` 综合 | 与 Tab 配对 |
| `pageNo` | **0 基** | 实测 pageNo≥1 恒空（报告写 1 起，实测修正为 0 基） |
| `sortType` | `0` | 默认排序 |

**签名（App 通道，ms 网关裸路径）**：

```
盐 salt = 68e251be8b49f462be367df22b212ee3        # ApiConfig.SECRET_KEY_MAP.search
有参: sign = MD5(参数按key排序 k=v 用&连接 + '&timestamp=' + 毫秒 + '&key=' + salt).upper()
无参: sign = MD5('timestamp=' + 毫秒 + '&key=' + salt)
```

**公共头（16 项，缺 productId 则 totalNum 恒 0）**：`productId=1605403829833195520`、
`platformCode=XIAOMI`、`versionId=7.9.0.24845`、`channel=cnrradio`、`equipmentId/uuid/yaud`（设备指纹，
任意唯一值均可，支持 `AUDIOFLOW_YUNTING_EQUIPMENT_ID` / `AUDIOFLOW_YUNTING_UUID` 覆盖）等。
每次请求使用独立毫秒时间戳（网关有 1051「重复访问随机数」拦截）。

## 三、行为细节

1. **Tab 策略**：专辑 tab（`searchTabId=2&contentType=1`）命中的条目才返回；
   实测部分关键词（如「三国演义」）该 tab `totalNum>0` 而 `data` 为空 → 必须回落综合 tab
   （`searchTabId=''&contentType=0`，0 基首页）。综合 tab 混有单集（contentType=3）、资讯（161/177），
   仅采纳 contentType=1；单集按 `albumId/parentId` 去重后逐个补 `/web/appAlbum/detail/<id>` 转成专辑条目。
2. **字段归一**（与其它平台一致）：`contentId→id`、`title→title`、`image→cover`、
   `childCount→episodes`、`listenCount→plays`、`endFlag→已完结/连载中`、`subtitle→description`。
3. **详情补全**：云听搜索条目不带主播名，走 `_enrich_search_result_details(limit=8)`
   并发拉详情补 `author/episodes/plays`（在线实测 ~0.5s，聚合搜索总耗时无感）。
4. **失败降级**：网关 1001/1050/404 转为明确告警并返回空列表，不影响其它平台与链接/ID 搜索。
5. **兼容不动**：`parse_url_or_id / get_album_info / get_album_singles / get_chapters / get_audio_url`
   对外行为不变；`get_album_detail` 返回体在统一字段外保留 `albumTitle/albumCover/total/des` 等旧键。

## 四、验证

- 单测：`pytest tests/test_yuntu_manager.py tests/test_search_performance.py` → 35 通过；
  全量 `pytest tests/` → 全绿（无回归）。
- 在线实测（本机直连 `ytmsout.radio.cn`）：
  - `search_books('三国演义')` → 78 个专辑（首位 15682083075740，300 集，播放 1630 万）；
  - `search_books('神雕侠侣', '云听FM')` → 3 条，首位 16606145480290 补全后 `author=云听有声书 / ep=348`；
  - 聚合 `search_books('神雕侠侣', 'all')` → 244 条，云听 3 条正常混排；
  - `get_album_chapters('16606145480290','云听FM')` → 348 章，含 playUrlHigh/playUrlLow。

## 五、遗留与建议

- 搜索接口为**免登录**接口，但设备指纹为固定演示值；若官方收紧校验，可改用随机化
  `equipmentId/uuid`（网关目前只验存在性）。
- 综合 tab 兜底里单集→专辑的详情补全最多 8 个专辑（budget=剩余条数），避免放大请求量。
- 防御面提醒（如需反馈官方）：路由先于验签的「路由存在性 oracle」、公共头不入签、
  时间窗校验偏宽，均与报告 F-002/F-007/F-008 一致。
