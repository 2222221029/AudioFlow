# 会话修复记录 —— 云听 CDN 403 批量下载失败（v1.0.48）

日期：2026-10-09　|　影响版本：<1.0.48　|　平台：云听FM

## 一、现象

用户报障：下载云听《倚天屠龙记》（专辑 17097974899240，592 集）时 100+ 集失败：

```
ERROR [云听FM][下载任务] 章节下载失败: 倚天屠龙记 第383集 - 云听FM下载失败:
403 Client Error: Forbidden for url: https://ytmedia.radio.cn/file/202408/...
task_id=web-488e7d3ee693 album_id=17097974899240 chapters=592
```

## 二、实测定位（2026-10-09 现场探针）

| 探针 | 结果 |
|------|------|
| CDN `ytmedia.radio.cn` 音频（此前成功过的 URL） | **恒 403**（openresty 页，150/552 字节两种），连续 6 次全 403 |
| 换 UA（浏览器/okhttp/App UA）、加 Referer、带 radio.cn 首页 Cookie | 全部 403，无差别 |
| 源站 `yunting-bj-radio-client.oss-cn-beijing.aliyuncs.com` 同 key | **200**，字节数与 CDN 报告一致，支持 Range（206）与 HEAD |
| 失败的第 383 集源站直拉 | 200，16,418,930 字节，真 MP3（`ID3`） |
| 全专辑 592 集抽样 20 集源站 | 20/20 成功 |
| 旧存储形态 `/CCYT%2F...`（编码斜杠）源站 | 200（key 逐字节原样保留即可，无需解码） |

**根因**：`ytmedia.radio.cn`（OSS 前置 CDN，openresty 网关）对单出口 IP 的
批量化拉流有阈值式封禁；大专辑（592 集）下载触发后，该 IP 的**所有**媒体请求
恒 403 —— 与 UA/Referer/Cookie/Range 无关，短间隔重试只会延长封禁。
旧代码裸 `requests.get` 单流直拉 CDN，无兜底通道。

## 三、修复（v1.0.48）

| 文件 | 变更 |
|------|------|
| `core/yuntu_manager.py` | ① `resolve_media_url`：CDN→源站域名解析（key 逐字节保留）；② `_audio_candidate_urls`：候选序列 [CDN, 源站]，冷却中反转；③ 类级 `_cdn_403_streak/_cdn_403_until` 全局冷却（默认连续 3 次 403 → 冷却 300s，`AUDIOFLOW_YUNTING_CDN_403_THRESHOLD/COOLDOWN` 可调，线程安全）；④ `download_audio`：走 `download_adapter.session_to_file` 分段并行下载，CDN 403/429 → 计冷却 + 立即换源站；`last_error_type` 归类 `rate_limited/restricted/transient`；⑤ `last_error/last_error_type` 属性 |
| `core/download_worker.py` | 云听分支：裸 requests 单流 → `download_manager.download_audio`（统一通道）；失败回填 `_error/_error_type` 交上层 `errors.should_retry` 决定重试；云听并发默认 6、上限 16（`YUNTING_DOWNLOAD_THREADS`），延缓触发 IP 风控 |
| `src/server/web_server.py` | ① 播放器 `direct_url` 分支解析到源站域名（播放也不受 CDN 风控影响）；② `_PLATFORM_AUDIO_HOST_HINTS` 云听白名单加 `yunting-bj-radio-client.oss-cn-beijing.aliyuncs.com`（SSRF 域名校验同步放行） |
| `tests/test_yuntu_manager.py` | +13 用例：域名解析（key 保留/%2F/非 CDN 直通）、候选顺序（含冷却反转）、阈值冷却/清零、download_audio 兜底成功/双失败归类/restricted 判定/空 URL 短路/分段通道接线、worker 分支接线 |
| `VERSION` / `frontend/package.json` | 1.0.47 → 1.0.48 |

## 四、验证

- 单测：`tests/test_yuntu_manager.py` 31 用例全绿；全量 `pytest tests/` 全绿（无回归）。
- 端到端（修复后代码，本机 IP 当时仍处 CDN 风控态）：
  - 第 383 集：CDN 403 → 自动切源站 → 200，16,418,930 字节，`ID3`，1.0s；
  - 第 384 集：同样兜底成功，16,213,294 字节；
  - 失败章节全量重下即可恢复（已有文件不会被覆盖逻辑误删）。

## 五、运维提示

- 用户重启后直接**重试失败章节**（下载管理 → 重试未完成）即可补齐，无需清库。
- 若 NAS 出口 IP 被持续风控（数小时不解），可设 `AUDIOFLOW_YUNTING_CDN_403_THRESHOLD=1`
  让云听下载全程直走源站。
- 播放（在线试听）同样已切源站，无需额外配置。
